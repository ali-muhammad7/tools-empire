## Planned architecture (for Stages 2–7)

- `src/app/` — App Router pages: `/` (home), `/tools/[slug]/` (one route per tool), plus `sitemap.ts` / `robots.ts` (Stage 6).
- `src/components/` — shared UI (header/nav, search, theme toggle, tool card, layout).
- `src/lib/tools.ts` — tool registry (slug, name, category, description, icon) driving nav, search, categories, and sitemap from one source of truth.
- `src/lib/` — pure, testable tool logic (formatters, encoders, generators) kept separate from UI so new tools plug in via the registry.
- Dark/light mode via CSS variables + `next-themes`-style class toggle (Stage 5); Tailwind v4 `@theme` tokens for the design system (Stage 2).
- Testing: unit tests for `src/lib` pure functions (Stage 6).
